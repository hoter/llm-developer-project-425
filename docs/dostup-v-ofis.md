# Пропуска и доступ в офис

## Постоянный пропуск

- Постоянный пропуск выдаётся в службе административного управления (АХО) в первый рабочий день.
- Для получения пропуска нужен паспорт и фотография.
- При утере пропуска немедленно сообщите в АХО — пропуск будет заблокирован, выдан новый.

## Гостевой доступ

- Гостевой пропуск оформляет сотрудник-приглашающий в системе пропусков не позднее, чем за 1 рабочий день до визита.
- Гость обязан находиться в офисе в сопровождении сотрудника.
- Разовый гостевой пропуск действует только в указанную дату.

## Вход и выход из офиса

- Офис открыт для сотрудников круглосуточно по постоянному пропуску.
- В нерабочее время проход по пропуску возможен только при активном пропуске.
- Забыли пропуск — обратитесь на ресепшен, вас пропустят по документу, удостоверяющему личность.

## Автомобиль и парковка

- Парковка для сотрудников — по заявке в АХО.
- Номер автомобиля заносится в список пропуска на парковку в течение 1 рабочего дня.
